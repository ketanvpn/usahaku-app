YANG HARUS DIKERJAKAN

1. RAPIIKAN IDENTITAS APLIKASI
- tetapkan nama aplikasi desktop yang rapi dan konsisten
- perbarui productName
- perbarui appId
- perbarui judul window Electron
- perbarui nama installer jika perlu
- pastikan branding konsisten di Electron config dan package metadata

2. ICON APLIKASI
- siapkan alur penggunaan file icon.ico
- hubungkan icon ke BrowserWindow dan electron-builder
- jika file icon final belum ada, buat placeholder config yang benar
- jelaskan di mana user harus menaruh file icon

3. FINAL CHECK DATABASE DESKTOP
- pastikan DATABASE_PATH di mode packaged benar-benar mengarah ke lokasi userData/AppData
- pastikan folder database dibuat otomatis jika belum ada
- pastikan jika app pertama kali dibuka, database otomatis siap
- tambahkan penanganan error jika database gagal dibuat

4. FINAL CHECK BACKUP / RESTORE / EXPORT
- pastikan backup JSON tetap nyaman digunakan di mode desktop
- pastikan restore tidak merusak data tanpa konfirmasi
- pastikan export CSV tersimpan dengan benar
- pastikan print tetap normal dari Electron

5. PENGALAMAN DESKTOP
- pastikan ukuran window default enak dipakai
- set minimum window size agar layout tidak rusak
- jika perlu, rapikan menu default Electron
- pertimbangkan apakah perlu hide menu bar agar tampilan lebih rapi
- pastikan tidak ada blank screen saat startup

6. ERROR HANDLING DESKTOP
- jika backend gagal start, tampilkan dialog error yang jelas
- jika frontend gagal dimuat, tampilkan pesan yang lebih manusiawi
- pastikan app exit dengan bersih
- pastikan proses backend tidak tertinggal setelah app ditutup

7. BUILD WINDOWS FINAL
- review electron-builder.yml
- pastikan target Windows sudah tepat
- cek output release folder
- pastikan file yang perlu ikut package sudah benar
- cek dependensi native seperti better-sqlite3 sudah ditangani dengan benar

8. README / PANDUAN USER
Perbarui README agar cocok untuk user awam:
- cara install aplikasi Windows
- akun default login

- cara backup

- cara build installer ulang bila diperlukan
